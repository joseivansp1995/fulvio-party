# Invitación Webapp Vaquera

Invitación digital moderna estilo vaquero/caballos, minimalista y completa.

## Incluye
- Portada con estética western moderna
- Animaciones suaves (aparición por scroll + microanimaciones)
- Cuenta regresiva automática
- Datos del evento
- Mapa embebido + botón de ubicación GPS
- Confirmación por WhatsApp con mensaje prellenado

## Personalizar rápido
Edita el objeto `invitationData` en `script.js`:
- `eventName`
- `eventDateISO`
- `dateText`
- `locationName`
- `gpsQuery`
- `whatsappNumber`

## Ejecutar
Solo abre `index.html` en tu navegador.

Si quieres publicarla online gratis, puedes usar GitHub Pages, Netlify o Vercel.
